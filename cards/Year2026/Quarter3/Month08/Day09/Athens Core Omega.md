# Athens Core Ω

This is an archive record for **Athens Core Ω**, a fast-paced 2D anime fighting game built around masked superheroes, transformation mechanics, and the Omega Centurion.

The record is intentionally compact for now. It keeps the project discoverable while leaving room for a later retrospective about the design decisions, production constraints, and lessons from the build.

## Project snapshot

- **Status:** Prototype
- **Platform:** Windows
- **Mode:** Local two-player fighting game
- **Team:** KGonzalezASC, Nicksternick, FMPO, and MaxMakesGames
- **Tools:** Unity and Aseprite

The project includes three playable characters with distinct archetypes, a universal transformation mechanic driven by an omega meter, palette variations, motion-input special moves, parries, and character-specific EX moves.
